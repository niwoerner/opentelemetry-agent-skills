# MySQL2 instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<SQL operation>` | CLIENT | `db.system.name="mysql"`; `db.query.text=<formatted or masked SQL>`; `db.namespace=<database>`; `server.address=<host>`; `server.port=<port>` | Created for `query` and `execute`; span name is the SQL text before the first space (normally the SQL operation). `maskStatement` and `maskStatementHook` control SQL value masking. Query errors set span status to ERROR; `responseHook` may run on successful responses and add custom attributes. `addSqlCommenterCommentToQueries` modifies non-prepared query text sent to MySQL. |
