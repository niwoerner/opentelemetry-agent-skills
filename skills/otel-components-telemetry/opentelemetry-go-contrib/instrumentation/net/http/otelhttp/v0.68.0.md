# otelhttp

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| operation (the `operation` argument) | SERVER | `http.request.method`, `url.scheme`, `server.address`, optionally `server.port`, `http.request.method_original`, `network.peer.address`, `network.peer.port`, `user_agent.original`, `client.address`, `url.path`, `network.protocol.name`, `network.protocol.version`, `http.route`, `http.response.status_code`, `http.request.body.size`, `http.response.body.size` | Server span; default name is the configured operation (custom `WithSpanNameFormatter` can replace it). `ReadEvents` and `WriteEvents` opt-in via `WithMessageEvents` add `read`/`write` events with `http.read_bytes`/`http.wrote_bytes`. Public endpoints configured with `WithPublicEndpointFn` create a new root and link a valid remote context. |
| HTTP {method} | CLIENT | `http.request.method`, `http.request.method_original`, `url.full`, `server.address`, optionally `server.port`, `network.protocol.name`, `network.protocol.version`, `http.response.status_code`, `error.type` | Created by `Transport`; response status and status-derived `error.type` are set on successful responses; transport/read/write errors set `error.type` and error status. |
