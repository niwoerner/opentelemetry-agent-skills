# PostgreSQL instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `pg.query:<OPERATION> <database>` | CLIENT | Stable: `db.system.name="postgresql"`, `db.namespace`, `server.address`, `server.port`, `db.query.text`; old: `db.system="postgresql"`, `db.name`, `db.connection_string` (masked), `db.user`, `net.peer.name`, `net.peer.port`; `db.operation.name`; `db.postgresql.values` (enhanced reporting); `db.postgresql.plan` (named prepared statement); `error.type` (callback errors) | Created by `client.query`; stable and old attributes are gated by `OTEL_SEMCONV_STABILITY_OPT_IN` database semconv selection. `requireParentSpan=true` suppresses emission without a parent. `requestHook`/`responseHook` may add custom attributes. Query errors record a sanitized exception event and set ERROR status. |
| `pg.connect` | CLIENT | Stable: `db.system.name`, `db.namespace`, `server.address`, `server.port`; old: `db.system`, `db.name`, `db.connection_string` (masked), `db.user`, `net.peer.name`, `net.peer.port` | Created by direct client connection; semantic-convention attributes are gated by `OTEL_SEMCONV_STABILITY_OPT_IN`. Suppressed by `requireParentSpan=true` without a parent or by `ignoreConnectSpans=true`; errors record a sanitized exception event and set ERROR status. |
| `pg-pool.connect` | CLIENT | Stable: `db.system.name`, `db.namespace`, `server.address`, `server.port`; old: `db.system`, `db.name`, `db.connection_string` (masked), `db.user`, `net.peer.name`, `net.peer.port`; `db.postgresql.idle.timeout.millis`; `db.postgresql.max.client` | Created by pool connection acquisition; semconv attributes are gated by `OTEL_SEMCONV_STABILITY_OPT_IN`. Suppressed by `requireParentSpan=true` without a parent or by `ignoreConnectSpans=true`; pool metrics remain enabled when connect spans are ignored. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.operation.duration` | Histogram | `s` | `db.namespace`; `server.address`; `server.port`; `db.operation.name`; stable `db.system.name`; old `db.system`; `error.type` (callback errors) | Recorded for instrumented query completions. Stable/old system attributes follow `OTEL_SEMCONV_STABILITY_OPT_IN`; `requireParentSpan=true` suppresses instrumentation without a parent. |
| `db.client.connection.count` | UpDownCounter | `{connection}` | `db.client.connection.pool.name`; `db.client.connection.state` (`used` or `idle`) | Recorded from pool connect/acquire/release/remove events; suppressed when instrumentation is skipped by `requireParentSpan=true`. |
| `db.client.connection.pending_requests` | UpDownCounter | `{connection}` | `db.client.connection.pool.name` | Recorded alongside pool state updates; suppressed when instrumentation is skipped by `requireParentSpan=true`. |
