# instrumentation-ioredis

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `connect` | CLIENT | `db.system.name="redis"`, `db.query.text="connect"`, `server.address=<host>`, `server.port=<port>` | Emitted only when an active parent span exists unless `requireParentSpan: false`. On failure, records an exception event and sets span status to ERROR. |
| `<redis command name>` | CLIENT | `db.operation.name=<command operation>`; `db.system.name="redis"`, `db.query.text=<serialized command>`, `server.address=<host>`, `server.port=<port>` | Emitted only when an active parent span exists unless `requireParentSpan: false`. Span name is the command name. The query value uses `dbStatementSerializer` when configured, otherwise the default serializer. `db.operation.name` is the command name, or `MULTI <command>` / `PIPELINE <command>` for queued transaction/pipeline commands (except `multi` and `exec`; support depends on ioredis version). On failure, records an exception event and sets span status to ERROR; `requestHook` and `responseHook` may add custom attributes. |
