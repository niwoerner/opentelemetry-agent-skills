# MongoDB instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `{operation} {collection}` (or `mongodb`) | CLIENT | `db.system.name="mongodb"`; `db.namespace`; `db.operation.name`; `db.collection.name`; `server.address`; `server.port`; `db.query.text` | Created for MongoDB v3 `insert`, `remove`, `update`, `command`, `query`, and `getMore`, and MongoDB v4–7 commands (excluding `ismaster`/`hello`). Requires an active parent span by default (`requireParentSpan=true`); set `requireParentSpan=false` to create root spans. `db.query.text` is serialized with values redacted by default, or includes values when `enhancedDatabaseReporting=true`; `dbStatementSerializer` can replace serialization. `responseHook` can add custom attributes. Errors set span status to ERROR. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.connection.count` | UpDownCounter | `{connection}` | `db.client.connection.pool.name`; `db.client.connection.state` (`idle`, `used`) | Emitted for MongoDB v4–7 server-session acquisition/release and `endSessions` connection-pool state changes. |
