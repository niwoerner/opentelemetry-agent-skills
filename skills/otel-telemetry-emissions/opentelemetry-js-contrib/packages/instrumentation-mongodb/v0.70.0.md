# MongoDB instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `mongodb.{operation}` | CLIENT | `db.system="mongodb"`; `db.name`; `db.mongodb.collection`; `db.operation`; `db.connection_string`; `net.peer.name`; `net.peer.port`; `db.statement` | Default when `OTEL_SEMCONV_STABILITY_OPT_IN` does not select database/network stable conventions. Created for MongoDB v3 `insert`, `remove`, `update`, `command`, `query`, and `getMore`, and MongoDB v4–7 commands (excluding `ismaster`/`hello`). Requires an active parent span by default (`requireParentSpan=true`). `db.statement` is redacted unless `enhancedDatabaseReporting=true`; `dbStatementSerializer` can replace serialization. `responseHook` can add custom attributes. |
| `{operation} {collection}` (or `mongodb`) | CLIENT | `db.system.name="mongodb"`; `db.namespace`; `db.operation.name`; `db.collection.name`; `server.address`; `server.port`; `db.query.text` | Emitted when `OTEL_SEMCONV_STABILITY_OPT_IN` includes `database` and/or `http` (stable tokens). With `database/dup` and/or `http/dup`, the corresponding old and stable attributes are emitted together. Stable database/network attributes are gated by those environment tokens. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.connections.usage` | UpDownCounter | `{connection}` | `pool.name`; `state` (`idle`, `used`) | Emitted for MongoDB v4–7 server-session acquisition/release and `endSessions` connection-pool state changes. This experimental metric is not controlled by `OTEL_SEMCONV_STABILITY_OPT_IN`. |
