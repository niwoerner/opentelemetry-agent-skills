# Express instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `router - {route}` | INTERNAL | `http.route`; `express.name`; `express.type="router"` | Emitted only when an active span already exists; router spans end immediately. `spanNameHook` may replace the name. |
| `middleware - {name}` | INTERNAL | `http.route`; `express.name`; `express.type="middleware"` | Emitted only when an active span already exists and the layer is not excluded by `ignoreLayers` or `ignoreLayersType`. Errors passed to `next` or thrown by the layer are recorded as an exception event and set span status to ERROR. `requestHook` may add custom attributes; `spanNameHook` may replace the name. |
| `request handler - {route}` | INTERNAL | `http.route`; `express.name`; `express.type="request_handler"` | Emitted only when an active span already exists and the layer is not excluded by `ignoreLayers` or `ignoreLayersType`. Errors passed to `next` or thrown by the layer are recorded as an exception event and set span status to ERROR. `requestHook` may add custom attributes; `spanNameHook` may replace the name. |
