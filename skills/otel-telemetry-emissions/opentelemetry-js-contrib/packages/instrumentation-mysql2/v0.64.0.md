# MySQL2 instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<SQL operation>` | CLIENT | `db.system.name="mysql"`; `db.query.text=<formatted or masked SQL>`; `db.namespace=<database>`; `server.address=<host>`; `server.port=<port>`; `db.system="mysql"`; `db.statement=<formatted or masked SQL>`; `db.connection_string="jdbc:mysql://<host>:<port>/<database>"`; `db.name=<database>`; `db.user=<user>`; `net.peer.name=<host>`; `net.peer.port=<port>` | Created for `query` and `execute`; span name is the SQL text before the first space (normally the SQL operation). Stable database attributes are gated by the `database` mode of `OTEL_SEMCONV_STABILITY_OPT_IN`; legacy database attributes by its `database/old` mode; stable network attributes by its `http` mode, and legacy network attributes by `http/old`. `maskStatement` and `maskStatementHook` control SQL value masking. Query errors set span status to ERROR; `responseHook` may run on successful responses and add custom attributes. `addSqlCommenterCommentToQueries` modifies non-prepared query text sent to MySQL.` |
