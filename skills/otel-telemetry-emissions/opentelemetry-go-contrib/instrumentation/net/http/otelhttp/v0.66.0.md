# otelhttp

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| operation (or the formatted operation and route) | SERVER | `http.request.method`, `url.scheme`, `server.address`, optionally `server.port`, `http.request.method_original`, `network.peer.address`, `network.peer.port`, `user_agent.original`, `client.address`, `url.path`, `network.protocol.name`, `network.protocol.version`, `http.route`, `http.response.status_code`, `http.request.body.size`, `http.response.body.size` | Created by `Handler`/`NewMiddleware`; custom `WithSpanNameFormatter` can replace the name. `ReadEvents` and `WriteEvents` opt in via `WithMessageEvents`, adding `read`/`write` events with `http.read_bytes`/`http.wrote_bytes`. `WithPublicEndpointFn` can make the span a new root and link a valid remote context. |
| HTTP {method} | CLIENT | `http.request.method`, `http.request.method_original`, `url.full`, `server.address`, optionally `server.port`, `network.protocol.name`, `network.protocol.version`, `http.response.status_code`, `error.type` | Created by `Transport`; response status and status-derived `error.type` are emitted on responses, while transport, response-body read, and protocol-switch write errors set `error.type` and error status. |
