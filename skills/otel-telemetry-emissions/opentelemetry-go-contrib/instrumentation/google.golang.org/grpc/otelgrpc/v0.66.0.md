# otelgrpc

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<package.service>/<method>` (full gRPC method without the leading slash) | Client or server | `rpc.method` (fully-qualified method), `rpc.system.name=grpc`, `rpc.response.status_code`; `server.address` and `server.port` when the gRPC peer address is available; custom `WithSpanAttributes` attributes | Spans are gated by `WithFilter`; kind defaults to client or server. The response status is the canonical gRPC code; server status is Error for Unknown, DeadlineExceeded, Unimplemented, Internal, Unavailable, and DataLoss. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `rpc.client.call.duration` | Histogram | s | `rpc.method`, `rpc.system.name=grpc`, `rpc.response.status_code`; custom `WithMetricAttributes`/`WithMetricAttributesFn` attributes | Emitted at RPC end. Filtered RPCs are not recorded. |
| `rpc.client.request.size` | Histogram | By | `rpc.method`, `rpc.system.name=grpc`; custom `WithMetricAttributes`/`WithMetricAttributesFn` attributes | Recorded for each outbound payload. Filtered RPCs are not recorded. |
| `rpc.client.response.size` | Histogram | By | `rpc.method`, `rpc.system.name=grpc`; custom `WithMetricAttributes`/`WithMetricAttributesFn` attributes | Recorded for each inbound payload. Filtered RPCs are not recorded. |
| `rpc.server.call.duration` | Histogram | s | `rpc.method`, `rpc.system.name=grpc`, `rpc.response.status_code`; custom `WithMetricAttributes`/`WithMetricAttributesFn` attributes | Emitted at RPC end. Filtered RPCs are not recorded. |
| `rpc.server.request.size` | Histogram | By | `rpc.method`, `rpc.system.name=grpc`; custom `WithMetricAttributes`/`WithMetricAttributesFn` attributes | Recorded for each inbound payload. Filtered RPCs are not recorded. |
| `rpc.server.response.size` | Histogram | By | `rpc.method`, `rpc.system.name=grpc`; custom `WithMetricAttributes`/`WithMetricAttributesFn` attributes | Recorded for each outbound payload. Filtered RPCs are not recorded. |
