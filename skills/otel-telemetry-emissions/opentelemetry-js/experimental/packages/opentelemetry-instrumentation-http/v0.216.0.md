# HTTP instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<HTTP method>` (updated to `<HTTP method> <http.route>` for incoming routed requests) | SERVER | Stable: `http.request.method`, `http.request.method_original` (if normalized), `url.scheme`, `server.address`, `server.port`, `network.peer.address`, `network.peer.port`, `network.protocol.version`, `client.address`, `url.path`, `url.query`, `user_agent.original`, `user_agent.synthetic.type`, `http.response.status_code`, `http.route`, `error.type`. Legacy: `http.url`, `http.host`, `net.host.name`, `http.method`, `http.scheme`, `http.client_ip`, `http.server_name`, `http.target`, `http.user_agent`, `http.request_content_length` or `http.request_content_length_uncompressed`, `http.flavor`, `net.transport`, response `net.host.ip`, `net.host.port`, `net.peer.ip`, `net.peer.port`, `http.status_code`, `http.status_text`, `http.route`, `http.error_name`, `http.error_message`. Also configured `http.request.header.<name>`/`http.response.header.<name>` and hook-supplied attributes. | `OTEL_SEMCONV_STABILITY_OPT_IN=http` emits stable only; `http/dup` emits both; default emits legacy only. Incoming instrumentation can be disabled or ignored by config. `enableSyntheticSourceDetection` gates `user_agent.synthetic.type`; `headersToSpanAttributes.server` gates captured headers; error attributes and the `exception` event are emitted on errors. |
| `<HTTP method>` | CLIENT | Stable: `http.request.method`, `http.request.method_original` (if normalized), `server.address`, `server.port`, `url.full`, `user_agent.original`, `user_agent.synthetic.type`, `http.response.status_code`, `network.peer.address`, `network.peer.port`, `network.protocol.version`, `error.type`. Legacy: `http.url`, `http.method`, `http.target`, `net.peer.name`, `http.host`, `http.user_agent`, response `net.peer.ip`, `net.peer.port`, `http.status_code`, `http.status_text`, `http.response_content_length` or `http.response_content_length_uncompressed`, `http.flavor`, `net.transport`, `http.error_name`, `http.error_message`. Also configured `http.request.header.<name>`/`http.response.header.<name>` and hook-supplied attributes. | `OTEL_SEMCONV_STABILITY_OPT_IN=http` emits stable only; `http/dup` emits both; default emits legacy only. Outgoing instrumentation can be disabled or ignored by config. `enableSyntheticSourceDetection` gates `user_agent.synthetic.type`; `headersToSpanAttributes.client` gates captured headers; error attributes and the `exception` event are emitted on errors. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.duration` | Histogram | ms | `http.scheme`, `http.method`, `net.host.name`, `http.flavor`, response `http.status_code`, `net.host.port`, `http.route` | Legacy metric emitted when `OTEL_SEMCONV_STABILITY_OPT_IN` is unset or `http/dup`. |
| `http.client.duration` | Histogram | ms | `http.method`, `net.peer.name`, response `net.peer.port`, `http.status_code`, `http.flavor` | Legacy metric emitted when `OTEL_SEMCONV_STABILITY_OPT_IN` is unset or `http/dup`. |
| `http.server.request.duration` | Histogram | s | `http.request.method`, `url.scheme`, `network.protocol.version` (if present), `http.response.status_code`, `http.route` | Stable metric emitted when `OTEL_SEMCONV_STABILITY_OPT_IN` is `http` or `http/dup`. |
| `http.client.request.duration` | Histogram | s | `http.request.method`, `server.address`, `server.port`, `http.response.status_code`, `network.protocol.version` (if present) | Stable metric emitted when `OTEL_SEMCONV_STABILITY_OPT_IN` is `http` or `http/dup`. |
