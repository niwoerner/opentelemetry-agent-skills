# Psycopg2

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| SQL operation name (first SQL token; database/system fallback) | CLIENT | `db.system`, `db.name`, `db.statement`, `db.user`, `net.peer.name`, `net.peer.port`; optionally `db.statement.parameters` | One span is emitted for `execute`, `executemany`, and `callproc`. `db.statement.parameters` requires `capture_parameters=True`. SQL comments are included in `db.statement` only with `enable_commenter=True` and `enable_attribute_commenter=True`. |
