# Psycopg2

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| SQL operation name (first SQL token; database/system fallback) | CLIENT | `db.system`/`db.system.name`, `db.name`/`db.namespace`, `db.statement`/`db.query.text`, `db.user`/`db.user.name`, `net.peer.name`/`server.address`, `net.peer.port`/`server.port`; optionally `db.statement.parameters` | One span is emitted for `execute`, `executemany`, and `callproc`. Attribute naming follows the database semantic-convention mode selected by `OTEL_SEMCONV_STABILITY_OPT_IN` (new mode: `database`; otherwise legacy). `db.statement.parameters` requires `capture_parameters=True`. SQL comments are included in statement/query attributes only with `enable_commenter=True` and `enable_attribute_commenter=True`. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `db.client.operation.duration` | Histogram | `s` | `db.system.name`, `db.namespace` (when database is set), `db.operation.name`, `server.address`, `server.port`, `error.type` (on error) | Emitted only when `OTEL_SEMCONV_STABILITY_OPT_IN=database`. Recorded for each operation; `error.type` is present only when execution raises. |
| `db.client.response.returned_rows` | Histogram | `{row}` | `db.system.name`, `db.namespace` (when database is set), `db.operation.name`, `server.address`, `server.port`, `error.type` (on error) | Emitted only when `OTEL_SEMCONV_STABILITY_OPT_IN=database`; recorded only for successful operations with a non-negative integer row count. |
