# Redis instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<Redis command>` (or `redis.search` / `redis.create_index`) | CLIENT | `db.statement` or `db.query.text`; `db.redis.args_length`; `db.system` or `db.system.name`; `db.redis.database_index`; `net.peer.name` or `server.address`; `net.peer.port` or `server.port`; `net.transport` or `network.transport`; `redis.create_index.index`, `redis.create_index.fields` (FT.CREATE); `redis.search.index`, `redis.search.query`, `redis.search.total`, and dynamic `redis.search.xdoc_<document>.<field>` attributes (FT.SEARCH) | Spans are emitted for synchronous/asynchronous, cluster, and immediate command execution when instrumentation is enabled. Legacy/new database and HTTP attribute names are selected independently by `OTEL_SEMCONV_STABILITY_OPT_IN` (`default`, `database`, `database/dup`; HTTP values `default`, `http`, `http/dup`). Unix-socket connections emit the peer path and transport; TCP connections emit host/port and transport. |
| `<space-separated Redis commands>` (or `redis` for an empty/invalid pipeline) | CLIENT | `db.statement` or `db.query.text`; `db.redis.pipeline_length`; `db.system` or `db.system.name`; `db.redis.database_index`; `net.peer.name` or `server.address`; `net.peer.port` or `server.port`; `net.transport` or `network.transport` | Emitted for synchronous/asynchronous pipelines and cluster pipelines. Attribute naming follows `OTEL_SEMCONV_STABILITY_OPT_IN` as above. |
