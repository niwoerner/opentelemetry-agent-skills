# FastAPI instrumentation

## Traces

| Span name | Kind | Attributes | Notes |
|---|---|---|---|
| `<HTTP method> <route>` (or route/method fallback) | SERVER or INTERNAL | HTTP request attributes (legacy: `http.method`, `http.scheme`, `http.host`, `net.host.port`, `http.flavor`, `http.target`, `http.url`, `http.server_name`, `http.user_agent`, `http.client_ip`, `net.peer.port`; stable: `http.request.method`, `server.address`, `server.port`, `url.scheme`, `network.protocol.version`, `url.path`, `url.query`, `user_agent.original`, `client.address`, `client.port`); `http.route`; response status (`http.status_code` or `http.response.status_code`); captured request/response headers when configured | HTTP and websocket scopes; excluded URLs and `OTEL_PYTHON_FASTAPI_EXCLUDED_URLS` suppress it. Stable HTTP attributes are selected by `OTEL_SEMCONV_STABILITY_OPT_IN=http`. |
| `<server span name> <scope type> receive` | INTERNAL | `asgi.event.type`; websocket status code when applicable | Unless `exclude_spans` contains `receive`. |
| `<server span name> <scope type> send` | INTERNAL | `asgi.event.type`; HTTP/websocket status code when applicable | Unless `exclude_spans` contains `send`. |
| `BackgroundTask <callable name>` | INTERNAL | - | Emitted when an instrumented Starlette/FastAPI background task runs. |

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `http.server.active_requests` | UpDownCounter | `requests` | HTTP server request dimensions; legacy uses `http.method`, `http.host`, `net.host.port`, `http.scheme`, `http.flavor`, `http.server_name`; stable uses `http.request.method`, `server.address`, `server.port`, `url.scheme`, `network.protocol.version`, `http.route` | HTTP scopes only; emitted in both legacy and stable modes. |
| `http.server.duration` | Histogram | `ms` | Legacy HTTP server dimensions plus `http.status_code`, `http.target` | Legacy mode; enabled when `OTEL_SEMCONV_STABILITY_OPT_IN` is unset/legacy. |
| `http.server.response.size` | Histogram | `By` | Legacy duration dimensions plus `http.status_code`, `http.target` | Legacy mode; only when response `Content-Length` is available. |
| `http.server.request.size` | Histogram | `By` | Legacy duration dimensions plus `http.status_code`, `http.target` | Legacy mode; only when request `Content-Length` is available. |
| `http.server.request.duration` | Histogram | `s` | Stable HTTP server dimensions plus `http.response.status_code`, `http.route` | `OTEL_SEMCONV_STABILITY_OPT_IN=http`. |
| `http.server.response.body.size` | Histogram | `By` | Stable HTTP server dimensions plus `http.response.status_code`, `http.route` | `OTEL_SEMCONV_STABILITY_OPT_IN=http`; only with response `Content-Length`. |
| `http.server.request.body.size` | Histogram | `By` | Stable HTTP server dimensions plus `http.response.status_code`, `http.route` | `OTEL_SEMCONV_STABILITY_OPT_IN=http`; only with request `Content-Length`. |
