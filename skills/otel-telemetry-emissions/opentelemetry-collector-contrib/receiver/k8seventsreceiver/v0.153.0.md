# Kubernetes Events Receiver

## Logs

| Log/event name | Attributes | Notes |
|---|---|---|
| `k8s.event` | `k8s.event.reason`, `k8s.event.action`, `k8s.event.start_time`, `k8s.event.name`, `k8s.event.uid`, `k8s.namespace.name`, `k8s.event.reporting_controller`, `k8s.event.reporting_instance`, `k8s.event.count` (when nonzero); resource attributes `k8s.node.name`, `k8s.object.kind`, `k8s.object.name`, `k8s.object.uid`, `k8s.object.fieldpath`, `k8s.object.api_version`, `k8s.object.resource_version` | `k8s.event.count` is omitted when the Kubernetes event count is zero. Severity is mapped from the event type when it is `Normal`, `Warning`, `Error`, or `Critical`. |
